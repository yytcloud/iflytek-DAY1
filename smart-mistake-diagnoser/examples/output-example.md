# 📝 错题诊断报告

> 学科：数学 · 年级：初一
> 题目编号：#001
> 诊断时间：2026年7月16日

---

## 📋 原题信息

**【题目】**
解方程：3(2x + 1) = 7x - 2

**学生答案**：x = 1

**正确答案**：x = -5

---

## 🔍 错误类型诊断

| 诊断维度 | 结果 |
|----------|------|
| 主要错误类型 | 计算失误（移项时符号错误） |
| 错误严重程度 | 中 |
| 涉及知识点 | 一元一次方程的解法、等式性质 |
| 关联前置知识 | 有理数运算（正负号规则） |

### 错误详细分析

让我们还原解题过程：
```
3(2x + 1) = 7x - 2
第一步展开：6x + 3 = 7x - 2    ← 这步正确
第二步移项：6x - 7x = -2 - 3   ← 学生可能在移项-2时忘记变号
第三步合并：-x = -5             ← 如果移项正确应得到此式
第四步求解：x = 5               ← 两边乘以-1
```

学生的答案 x = 1，最可能的错误发生在第二步移项时：
- 将 -2 移到左边时**忘记变号**，写成了 `6x - 7x = -2 + 3`，得到 `-x = 1`，从而 `x = -1`
- 或者在合并 `3 = -2` 时算成了 `3 + 2 = 5`，方向搞反

**核心问题**：移项时未正确运用等式性质，常数项移项后符号未改变。

---

## 💡 正确解法讲解

### 解题思路

```
3(2x + 1) = 7x - 2

步骤1：去括号（分配律）
  6x + 3 = 7x - 2

步骤2：移项（含x的移左边，常数移右边）
  6x - 7x = -2 - 3
  ⚠️ 注意：-2移到右边变成+3（变号！）

步骤3：合并同类项
  -x = -5

步骤4：系数化为1（两边同乘-1）
  x = 5
```

### 易错点提醒
⚠️ 移项的本质是"等式两边同时加/减同一个数"，移动的那一项**必须变号**
⚠️ 检查时可以把解代回原方程验证：3(2×5+1) = 3×11 = 33，7×5-2 = 33 ✓

### 记忆小技巧
💡 "移项变号口诀"：左变右变，正变负变；移哪边，哪边变，不动不变。

## 📊 变式练习

### 变式题 1（基础巩固）
**【题目】** 解方程：2(3x - 1) = 5x + 4
> 💡 提示：先去括号，再移项，注意常数项变号。

**【参考答案】**
```
6x - 2 = 5x + 4
6x - 5x = 4 + 2
x = 6
```
验证：2(3×6-1) = 2×17 = 34，5×6+4 = 34 ✓

---

### 变式题 2（稍有变化）
**【题目】** 解方程：4(x + 2) - 3(2x - 1) = 5
> 💡 提示：两边都有括号，先分别展开，再合并含x的项。

**【参考答案】**
```
4x + 8 - 6x + 3 = 5
-2x + 11 = 5
-2x = 5 - 11
-2x = -6
x = 3
```

---

### 变式题 3（综合应用）
**【题目】** 小明买了3本笔记本和2支钢笔，共花了35元。已知一本笔记本比一支钢笔贵3元，求笔记本和钢笔的单价。
> 💡 提示：设钢笔单价为x元，列方程求解。

**【参考答案】**
设钢笔单价为 x 元，则笔记本单价为 (x+3) 元。
```
3(x + 3) + 2x = 35
3x + 9 + 2x = 35
5x = 35 - 9
5x = 26
x = 5.2
```
钢笔：5.2元，笔记本：8.2元。
