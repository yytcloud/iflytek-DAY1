# 用户输入示例

## 示例 1：项目周会转写文本
张总：好，开始今天的周会。首先来看一下上周的进度。李明，你负责的用户模块怎么样了？
李明：用户模块的注册和登录功能已经开发完毕，正在做单元测试，预计周三可以提测。
张总：好的，提测后尽快安排QA验证。王芳，前端页面进度如何？
王芳：首页和列表页已经完成，详情页还差一点，主要是图片上传的交互还需要调整。
张总：图片上传这个功能很重要，能不能本周内搞定？
王芳：应该可以，我周四之前完成。
张总：好。另外，关于服务器扩容的事，上次开会说要做，陈工，这个进度呢？
陈工：已经提交了扩容申请，还在等运维审批，大概还需要两三天。
张总：催一下，月底之前必须扩完，不然上线会有问题。最后说一下下周的计划，下周五要做一次全量测试，所有人提前做好准备。
